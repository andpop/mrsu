# Task03 — «Простое ли число?»

Веб-приложение (SPA) — игра, в которой игроку предлагается случайное целое число, и он должен определить, является ли оно простым.

## Запуск приложения

### 1. Установить зависимости

```bash
cd Task03
composer install
```

### 2. Запустить локальный веб-сервер

```bash
php -S localhost:3000 -t public
```

### 3. Открыть в браузере

```
http://localhost:3000/
```

База данных `db/prime.db` создаётся автоматически при первом запросе.

## Требования

- PHP >= 8.0 с расширениями `pdo`, `pdo_sqlite`
- Composer

# Арифметическая прогрессия

Веб-приложение "Арифметическая прогрессия" на Laravel.

## Установка
make install
cd Task04/laravel
php artisan serve
После запуска откройте в браузере: http://localhost:8000


## Использование
1. Введите имя игрока
2. Нажмите "Новая игра"
3. Угадайте пропущенное число в арифметической прогрессии
4. Результаты сохраняются в базе данных и отображаются в истории игр

## Структура проекта
1. app/Models/ - модели Game, Progression, ProgressionNumber
2. app/Http/Controllers/ - контроллеры
3. database/migrations/ - миграции базы данных
4. resources/views/ - шаблоны представлений
5. routes/ - маршруты приложения
